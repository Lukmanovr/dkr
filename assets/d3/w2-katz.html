Interactive · Katz centrality: one dial from degree to the eigenvector

Katz centrality counts every walk that ends at a node and discounts a walk of length k by βk, so the single number β decides how far an endorsement travels. Near β = 0 only one-step walks count and Katz is degree in disguise: the hub S, with six edges, leads. As β climbs toward 1/λmax ≈ 0.315 the long walks dominate and the leading eigenvector takes over: the clique's members keep endorsing one another while a leaf can only pass on an endorsement it never received, so K1 overtakes S at the tipping point β* = 0.200 — this graph is built so that the two extremes disagree. Try this: drag the slider slowly to the right until the top bar changes and note the β at which it happens; then watch each bar's end travel from its degree tick toward its eigenvector tick, which is the whole degree → Katz → eigenvector sequence performed by one dial.
