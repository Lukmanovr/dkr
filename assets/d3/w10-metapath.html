Interactive · Metapaths: different lenses, different neighbors

A metapath is a typed walk recipe, and each recipe manufactures a different homogeneous graph from the same data — which is exactly what HAN aggregates over, one attention head per lens. Try this: for a1, the three lenses give three disjoint answers: co-author {a2}, same-venue {a2, a3}, cited-by {a4}. Then try a5, whose co-author set is empty but whose venue set is not — the lens, not the data, decides who counts as close. Choosing metapaths IS feature engineering, with everything Week 2 taught about its costs.
